# Leafling Habitat v1

Runtime outputs:

- `public/leafling-habitat-backdrop-v1.png` — 480 × 240 opaque panorama
- `public/leafling-shelter-tree-v1.png` — transparent tree sprite, normalized to 176 × 196
- `public/leafling-meadow-foreground-v1.png` — transparent 480 × 64 near-ground strip

All sources use the Study 10 social card as a palette and rendering reference. Chroma-key sources use perfectly flat `#ff00ff`; the key is removed before runtime packaging. The scene remains permanently weather-neutral so engine lighting and precipitation can act on one continuous place.
