## Provenance

- Product: Airbnb iOS app
- Surface: Home listing detail

- Evidence: five user-supplied screenshots at 1179 x 2556
- Exact app version and listing URL: not recorded

Airbnb described its Design Language System as a native-first effort built from
shared principles and reusable components. The original public account is
[Building a Visual Language](https://medium.com/airbnb-design/building-a-visual-language-behind-the-scenes-of-our-airbnb-design-system-224748775e4e).
Airbnb's [2025 Summer Release](https://news.airbnb.com/product-releases/airbnb-2025-summer-release/)
documents the later all-new mobile app, but it does not publish the production
design system or grant Kwilt implementation rights.

## Usage boundary

These captures are third-party copyrighted product evidence retained for
internal design research. Do not redistribute them, import them into production,
extract their photography, trace their glyphs, reuse branded badges, or present
their pixel values as Kwilt tokens. Semantic ideas such as a facts list or a
persistent decision region must be rebuilt with Kwilt-owned components, icons,
tokens, language, behavior, and accessibility proof.
