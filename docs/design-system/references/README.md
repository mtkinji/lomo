# External UI references

This library preserves time-bounded product evidence that can improve Kwilt's
composition judgment. It is not a second design system.

External products may demonstrate useful hierarchy, pacing, disclosure, or
interaction relationships. They do not provide Kwilt tokens, components,
canonicality, product behavior, or permission to copy distinctive visual
expression or assets.

Every study records:

- source product, platform, capture date, and screen context;
- the job and observed three-second read;
- a `Preserve / Translate / Reject` ledger;
- Candidate Kwilt patterns the evidence may inform;
- asset and redistribution limits;
- the date at which the observations should be refreshed.

Screenshots stay in this research directory. Production code must not import
them. A derived composition becomes a Kwilt precedent only when it is recorded
in the Pattern Atlas, rebuilt with Kwilt-owned components and tokens, rendered
on a real route, and accepted through the atlas maturity process.
