**Goal:** Add a small privacy-safe iOS Home Screen widget that opens Unified Chat to a fresh unsent composer and creates a durable thread only on first send.

**Architecture:** Extend the existing generated WidgetKit bundle with a static Chat widget and a bounded `entry=fresh` deep link. Project a threadless workbench snapshot through the existing native/hosted protocol, then create exactly one normal durable thread just in time before the first run. Preserve ordinary Chat entry, voice consent, capability ownership, and all existing widget families.

**Tech Stack:** Expo SDK 54, React Native, TypeScript, React Navigation linking, native `react-native-webview` bridge, WidgetKit/SwiftUI generated by Expo config plugin, Jest, Node test runner.

**Implementation precondition:** The current checkout has user-owned Focus-widget edits in `plugins/withAppleEcosystemIntegrations.js`, `scripts/apple-widget-generator-contract.test.mjs`, and `src/navigation/linkingConfig*`. - [ ] **Step 3: Implement the small single-flight gate**

```ts
export function createFreshEntryThreadGate<TThread, TAggregate>(deps: {
  create: () => Promise<TThread>;
  load: (thread: TThread) => Promise<TAggregate>;
}) {
  let pending: Promise<TAggregate> | null = null;
  return {
    ensure(): Promise<TAggregate> {
      if (!pending) {
        pending = deps.create()
          .then(deps.load)
          .finally(() => { pending = null; });
      }
      return pending;
    },
  };
}
```
