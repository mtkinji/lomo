# Yes-And: transaction-rule-truth

## Expansion decision

Skip broad expansion. This is a bounded trust refinement, not a request for a general automation center.

## Job elevation

Yes, and the real job is larger than suppressing a redundant CTA: every automation offer should distinguish **current result**, **source of that result**, and **future behavior**. Applying that truth contract here makes transaction review more trustworthy without expanding the surface.

## Adjacencies deliberately deferred

- Global rule inventory and editing.
- Rule conflict detection across merchants or categories.
- Analytics about automation coverage.
- AI suggestions for rule scope.
- Household-shared rules.

## Frame recommendation

Run the loop with the original frame: make merchant-rule truth explicit at the point of transaction review.
