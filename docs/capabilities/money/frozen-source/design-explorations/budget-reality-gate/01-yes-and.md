# Yes-And: budget-reality-gate

Original idea: scaffold the first value unit for Kwilt Money around shared
Kwilt personas, JTBDs, and a concrete budget review loop.

**Yes, and what if it could...** turn each meaningful spending context into a live resource meter instead of a static category budget.

- Serves: `jtbd-carry-intentions-into-action`
- Job elevation: the budget intention is carried to the moment where spending happens.
- New value: Maya can see runway and pace for DoorDash, Amazon household, Amazon work, or another context without opening a ledger.
- Cost delta vs. original: low
- Anti-pattern check: pass if the meter stays plain and action-oriented.

**Yes, and what if it could...** make "leave blocked" a respected successful outcome.

- Serves: `jtbd-put-intention-before-impulse`
- Job elevation: intentional restraint becomes as valid as intentional access.
- New value: the user can decide "not now" without feeling failed.
- Cost delta vs. original: low
- Anti-pattern check: pass if copy avoids celebration, streaks, or guilt.

**Yes, and what if it could...** remember the review as a small household proof point.

- Serves: `jtbd-trust-this-app-with-my-life`
- Job elevation: the user can trust that the gate is based on visible review, not hidden judgment.
- New value: recent reviews explain why access was opened or left blocked.
- Cost delta vs. original: medium
- Anti-pattern check: pass if history is private, local to the user/household, and not framed as compliance.

**Yes, and what if it could...** start with fixture/manual lane data but preserve the shape for real financial data later.

- Serves: `jtbd-trust-this-app-with-my-life`
- Job elevation: the learning release can test the behavior before requiring sensitive bank integrations.
- New value: faster truthful learning without prematurely asking for Plaid-level trust.
- Cost delta vs. original: low
- Anti-pattern check: pass if the app is honest that the lane is manually maintained in the learning slice.

**Yes, and what if it could...** connect to Kwilt's Screen Time philosophy as "chosen pause" rather than restriction.

- Serves: `jtbd-put-intention-before-impulse`
- Job elevation: the access rule supports agency at the impulse moment.
- New value: Kwilt Money inherits Kwilt's trust model instead of feeling like parental controls.
- Cost delta vs. original: medium
- Anti-pattern check: pass if setup is explicit, visible, reversible, and non-shaming.

**Yes, and what if it could...** become a family coordination primitive later.

- Serves: `jtbd-invite-the-right-people-in` as a future adjacency
- Job elevation: one household member can help others see spending reality without surveillance.
- New value: shared rules and shared lanes could make household budgeting collaborative.
- Cost delta vs. original: high
- Anti-pattern check: defer; this would fail if built before trust and solo value are proven.

## Frame Recommendation

Run `design-thinking-loop` with the expanded frame: "budget reality gate."

The original scaffold is right, but the value unit is not just documentation. It
is one configured app-to-meter rule plus one intentional review outcome. The
underlying model should support multiple meters and mappings, while the first
release should make one loop feel complete before adding broader budget
features.
