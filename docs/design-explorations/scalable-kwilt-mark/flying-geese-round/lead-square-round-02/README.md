# Kwilt Mark: Faithful Square Leads — Round 02

Status: visual exploration only. No production logo, app icon, or lockup has changed.

This round replaces the rejected redraws from Square Leads Round 01. It does not invent new vector silhouettes. Instead, it extracts the approved T2 and K3 artwork directly from the Duel Round 01 board and applies one controlled transformation: horizontal expansion until the occupied artwork bounds equal their existing height.

## Leads

- **Thread Path — T2:** approved occupied bounds were `177 × 204`; horizontal scale factor is `204 / 177`, approximately `1.153`.
- **Nested K — K3:** approved occupied bounds were `151 × 190`; horizontal scale factor is `190 / 151`, approximately `1.258`.

Every original piece, curve, interruption, and negative-space relationship is retained. Both final PNG masters are `1024 × 1024`, with exact `768 × 768` occupied bounds centered inside the canvas.

If either is accepted, the next step is to trace that exact transformed silhouette into deterministic SVG geometry and test the vector in the real 28-pixel lockup.
