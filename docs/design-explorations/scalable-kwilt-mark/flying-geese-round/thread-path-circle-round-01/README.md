# Kwilt Mark: Thread Path Circle — Round 01

Status: visual exploration only. No production logo, app icon, or lockup has changed.

This direction translates the Thread Path into a circular field rather than placing the earlier mark inside a decorative ring.

## Construction

- A true circle provides the mark's outer boundary.
- Three equal-width channels share one exact 45-degree axis and equal spacing.
- One staggered bridge interrupts each channel, making the path appear to pass behind the fabric and return.
- The bridge phase changes from row to row, preserving the original Thread Path rhythm without reproducing the tall T2 silhouette.
- The channels reach the perimeter, so the pattern and circle behave as one mark.
