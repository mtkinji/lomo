# Diverge: To-Do Attachment Previews

Axis of variation: how much visual prominence attachments receive inside Activity Detail.

## Thumbnail gallery

A horizontal rail favors visual recognition for photos and videos. It is strongest for media sets but weak for mixed documents and audio, and off-screen items are easier to miss.

## Enhanced attachment rows

One universal card uses a generous media slot, filename, useful metadata, upload state, and a whole-card preview action. It handles mixed media consistently and fits the existing detail hierarchy.

## Primary preview with compact remainder

The first attachment receives a large preview and later attachments become compact rows. It works for a single important photo but invents a primary hierarchy the model does not own.

All alternatives keep attachments Activity-owned, avoid blocking capture, and add no dashboard, streak, forced organization, or public-sharing behavior.
