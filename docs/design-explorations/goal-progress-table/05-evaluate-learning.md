# Evaluate Learning: Goal Progress Table

## Learning questions

- Does the table make Charlie willing to put the county-high-points goal in Kwilt?
- Can he paste the existing note with little or no manual cleanup?
- Does he understand that every summit row is a real To-do and that County/Elevation are Goal-specific data about it?
- Is the text editor sufficient after import, or does he need direct cell editing?
- Does row completion feel calm and useful rather than like productivity scoring?

## Evidence plan

Supporting evidence:

- Charlie chooses Kwilt over the manually formatted note for the shared goal.
- The first paste produces the intended three columns and most or all 29 rows.
- He checks and later revisits at least one real completed county.
- Existing Naomi Peak and Thurston Peak To-dos gain their custom data without duplication.
- He does not ask for percentages, filters, or a separate dashboard to make the table useful.

Disconfirming evidence:

- He keeps the Note as the authoritative copy.
- Parsing requires repeated manual repair.
- He expects to edit cells directly and finds source-text editing unnatural.
- The table feels hidden, cramped, or visually less trustworthy than the Note.
- He expects both accounts to co-edit immediately and the current sharing boundary breaks trust.

Brand-goodwill evidence:

- The feature feels deliberately part of the Goal rather than an experimental dev control.
- Existing Goals remain calm and unchanged.
- No completion state is lost when table text is corrected.

## Instrumentation

- Observe the first import and note the number of cleanup edits.
- Record a short interview after setup and after the first real high-point outing.
- Capture whether the Note remains in parallel and which copy is treated as authoritative.
- Use source/unit verification for persistence and row reconciliation.
- Do not track cell contents, county names, or row-level behavior remotely for this learning release.

## Decision rule

Proceed toward permanent capability after Charlie uses it as the authoritative To-do view across at least two real outings and one other Goal successfully defines its own useful columns. Revise the editor if adoption is blocked by cell correction, title-column inference, or import cleanup. Reframe if the demand expands into a general spreadsheet rather than Goal-specific To-do data.

## Expected next action

Run the local bundled slice with the real 29-row note, then decide whether direct cell editing or shared content synchronization is the next smallest justified extension.
