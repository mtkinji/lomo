# Learning release

- One standard Share Plan bottom guide with scrim.
- Signed-in Household people remain selectable when available.
- Messages, Email, Copy link, and More create/reuse one guest link per open guide.
- Seven-day default expiry, 30-day ceiling, hashed token, revocation, 100-response
  capacity, and no direct guest table access.
- Hosted response: select every meal the guest would eat, optionally suggest one
  missing meal up to 240 characters, and optionally add a display name up to 80
  characters. Guest choices cannot create a consequential hard pass.
- The task is visible before explanation, optional identity, or app promotion.
- The regular Plan combines guest choices with positive support on existing
  meal rows. A compact organizer receipt preserves suggestions that have no row.
- After a successful response, offer `Get Kwilt free` with the benefit of
  keeping meal ideas, family input, and groceries together. Completing the web
  task never requires installation.
- No app deep-link promise until a real guest-feedback app destination exists.
