# UI Contract: Chat Recipe Proposal

Job: When a useful recipe or correction is already in Chat, the user needs to review the exact durable Recipe consequence so they can preserve it without repeating the work or accepting a silent change.

Authority chain: feature brief → Unified Chat proposal/receipt contract → hosted compact proposal precedent → local workbench typography and actions.

Three-second read: Create, update, or delete this named Recipe?

Primary action: Create / Update / Delete.

Primary information: Recipe name and the operation consequence.

Secondary information: ingredient and step counts for creation; immutable-version reassurance for update; private-library removal warning for delete.

Reveal later: full recipe content remains in the surrounding Chat response/evidence and authoritative Recipe Home after apply.

Scan order: action eyebrow → Recipe title → compact consequence → primary decision.

Must not add: a Recipe-specific modal, nested card, settings, extra confirmation after the proposal, raw IDs, version numbers, or a second primary action.

Reuse map: proposal boundary → existing compact proposal card; decision → existing proposal approve/reject/defer controls; success → existing receipt and object-open action.

Nearest precedent: compact To-do proposal; same one-decision card and action placement, different capability nouns and destructive copy.

External exemplar ledger: user screenshot, 2026-08-16 → preserve the in-thread proposal placement; translate to Recipe-owned typed action and review copy; reject the refusal text and generic Activity-style recipe card.

Behavior sources: create/update/delete confirmation and receipts from `brief-chat-recipe-management`; navigation from `recipesChatAdapter`; persistence from Recipe repository contracts.

Unresolved decisions: whether long recipes eventually need an inline Recipe-owned field review; excluded from this learning release.

Required states: pending, deferred, applying, applied receipt, failed/stale, and destructive delete.

Proof path: actual native Unified Chat route using the hosted workbench on iPhone 17 Pro Simulator; create, reject/defer, update, stale update, delete, applied receipt, and Recipe Home return.
