# Diverge: Exploration Recap

Axis of variation: interruption timing and confidence ownership.

## A - Per-place celebration

Celebrate each named arrival immediately. It is legible but fails the calm UX bar when several places are crossed in one outing.

## B - Manual review queue

Collect candidates and ask the user to approve each one later. It improves correctness but turns a walk into administrative cleanup and violates capture-first.

## C - Session recap

Silently accumulate bounded, high-confidence discoveries; close the session explicitly or after credible background stillness; then show one route-ordered recap. Incorrect automatic visits remain removable. This best balances presence, meaning, and trust.

## D - Weekly family digest

Aggregate opted-in family discoveries into a weekly story. It is emotionally promising but depends on remote identity, sharing, revocation, and retention infrastructure that is not present.

## Recommendation

Build C. Retain A only as a subtle in-app motion when the recap opens, and defer D until family sharing is authoritative.
