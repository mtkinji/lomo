# Diverge: Compound Recipe Instructions

Axis: where atomicity lives.

## Flat atomic steps

Every sentence becomes another top-level numbered step. This is simple, but it turns the starter catalog's 2,410 authored phases into a much longer sequence and removes useful grouping. Reject.

## Shared phases with ordered cues

Each existing instruction remains a numbered phase and gains one or more stable cues. Recipe Home shows the phase with all cues; Cook Mode flattens cues while retaining phase/action context. This fits the current domain and prevents content drift. Prefer.

## Guided-only decomposition

Recipe Home retains paragraphs while Cook Mode privately splits them into cues. This keeps the detail page unchanged but creates two interpretations of the Recipe and makes editing, resuming, timers, and accessibility harder to reason about. Reject.
