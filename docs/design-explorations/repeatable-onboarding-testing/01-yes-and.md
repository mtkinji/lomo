# Yes-And: Repeatable Onboarding Testing

The broader opportunity is an onboarding QA harness, but the requested slice is concrete and developer-only. Expanding it into account pools, automated signup, analytics dashboards, or backend reset APIs would add authority and maintenance without improving the immediate test loop.

Job elevation: preserve two named proof modes—**clean install + new identity** for first-run truth, and **reset & replay** for rapid flow iteration.

Frame recommendation: **Skip expansion and ship the original, bounded harness improvement.**
