# Yes-And: Chat-Authored Personal Screen Time Limits

Original idea: make the failed self-directed request repeatably actionable through Chat.

The useful adjacencies are narrow: preserve self versus child identity, carry any app label, carry any 1–1440 minute daily allowance, survive conversational subject correction, reuse the canonical builder, and expose the saved rule in the existing inventory. Expanding into arbitrary automation, usage analytics, per-session timers, family authority, or Chat-held Apple tokens would dilute the trust job and enlarge the native proof surface.

Frame recommendation: run the loop with the original generic self-limit frame.
