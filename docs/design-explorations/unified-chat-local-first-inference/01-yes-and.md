# Yes-And: Unified Chat local-first inference

1. **Yes, and tiny social turns can require no model at all.** A small authored response set removes cost and cold-start variance where generation adds no value.
2. **Yes, and bounded writing help can stay on the phone.** Rephrasing, shortening, proofreading, and small ideation tasks can use Apple's model when available.
3. **Yes, and local failure can be invisible.** The existing cloud answer remains the fallback, so eligibility never becomes a user-visible dead end.
4. **Yes, and privacy can be structural.** The first release excludes private Kwilt evidence instead of asking a local model to interpret a complicated data boundary.
5. **Yes, and routing can become provider-neutral.** A typed task contract lets future Android or improved local providers fit behind the same eligibility rules.
6. **Yes, and dogfood can measure the real trade.** Route, availability, duration, fallback reason, and outcome can be measured without logging prompt or generated text.

Job elevation: local inference is valuable when it makes Kwilt calmer, faster, and cheaper without asking the user to understand model infrastructure.
