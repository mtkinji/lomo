# Yes-And: Family Screen Time Direct Controls

## Original idea

Use Chat to block named apps for named children for a bounded duration.

**Yes, and what if one command could cover several children without repeated setup?**

- Serves: `jtbd-carry-intentions-into-action`
- Job elevation: one family decision becomes one reviewed batch.
- New value: validate every child and selection first, then apply or clearly decline the whole batch.
- Cost delta: medium.
- Anti-pattern check: pass; no family dashboard or bulk “all children” default.

**Yes, and what if the same saved selection could be reused in future conversation?**

- Serves: `jtbd-trust-this-app-with-my-life`
- Job elevation: the one-time Apple picker ceremony pays off repeatedly.

- Cost delta: low after native selection storage exists.
- Anti-pattern check: pass if Kwilt stores only selected handles, not installed-app inventory.

## Job elevation

The idea is not a remote toggle. It is a small family command language over saved, privacy-preserving selections with bounded time, explicit scope, causal receipts, and safe expiry.

## Frame recommendation

Run the loop with the expanded frame: **direct family controls** include block, allow, inspect, cancel, and optionally promote-to-agreement. Build block + inspect + cancel first.
