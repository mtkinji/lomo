# Yes-And: Money Capability First Entry

## Decision

Skip expansion. This is a bounded refinement inside the already accepted progressive capability
onboarding model, not a new capability, platform, or open-ended surface.

## Job-elevation note

The useful elevation is already contained in the frame: Budgets, Transactions, and Accounts are
three places inside one Money job. The design should make that shared ownership legible through
behavior without adding a Money onboarding hub, destination-specific tours, or another capability
taxonomy.

## Frame recommendation

Run the loop with the original frame.
