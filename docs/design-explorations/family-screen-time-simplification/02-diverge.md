# Diverge: Simple Native Administration And Chat Control

Axis: native-first versus conversation-first versus default-first.

## A. Quiet Agreement Card

Charlie's Household page owns one compact card showing the current agreement, today's child explanation, and one action. Setup is progressive: connect device, choose apps, accept or customize the starter agreement, preview, turn on. Chat reads and changes the same agreement through typed proposals, but the native card remains the canonical editor and status surface.

- Persona fit: strongest for Maya; predictable and easy to revisit.
- System fit: strong; preserves Household ownership and native setup.
- Best when: parents mostly maintain a stable rule.
- Fails when: a caregiver expects every adjustment to finish conversationally.
- Anti-pattern check: pass.

## B. Conversational Control Center

Chat becomes the primary setup and management experience. It asks one missing question at a time and renders a compact proposal card. Native surfaces exist mainly for Apple authorization, picker, and device repair.

- Persona fit: strong for Nina, mixed for Maya.
- System fit: weak; risks making Chat the owner of family policy and discoverability.
- Best when: the user already lives in Chat and expresses nuanced intent naturally.
- Fails when: the family wants a stable place to inspect or edit the current agreement.
- Anti-pattern check: fails if conversation becomes the only authoritative surface; fix by retaining the native child card.

## C. One-Tap Starter Plan

After device connection, Kwilt offers “School-day Games” with Games, weekdays 4–7 PM, and 30 minutes per day. The caregiver can turn it on immediately or customize. Chat can invoke the same starter plan by name and propose specific edits later.

- Persona fit: strongest activation fit for Maya.
- System fit: strong; the current learning rule already supplies the default.
- Best when: the first value is more important than configuration breadth.
- Fails when: school schedules differ substantially.
- Anti-pattern check: pass if customization remains easy and the preset is not framed as universal parenting advice.

## D. Sentence Composer Everywhere

Native and Chat share one sentence-shaped editor: “Games are available on weekdays from 4–7 PM for 30 minutes.” Native taps edit each phrase; Chat rewrites the same typed fields and shows the revised sentence for confirmation.

- Persona fit: strong comprehension, moderate interaction risk.
- System fit: medium; responsibility criteria could make the sentence crowded.
- Best when: one simple rule remains the product boundary.
- Fails when: long app labels, multiple responsibilities, or accessibility text scaling make inline editing brittle.
- Anti-pattern check: pass if the sentence is a summary rather than a rule-builder canvas.

## Conclusion

Combine A and C. Use the readable sentence as shared presentation grammar, not as an inline editing requirement. Chat remains an alternate controller over the same typed agreement.
