# Frame: Unified Plan Reaction Guide

## What the user said

> Have one reaction affordance, put positive and negative choices inside it, use section labels rather than labels on every option, and render it in the new floating bottom guide.

## Target audience and job

Maya, an aspirational family organizer, needs household members to register a quick, truthful preference without making meal planning feel like a formal vote.

- Hero anchor: `jtbd-move-the-few-things-that-matter`
- Active anchors: `jtbd-invite-the-right-people-in`, `jtbd-trust-this-app-with-my-life`
- Job-flow step: Gather household input, currently `3/5`.

## System alignment

Constraint posture: `Fit the system`.

- Keep the existing one-response-per-person model and separate positive/downvote counts.
- Reuse the existing Plan reaction row and project-owned `BottomGuide`.
- An idle affordance must not resemble recorded negative feedback.

## Design challenge

How might we help Maya's household respond in seconds while preserving truthful state, calm hierarchy, and one obvious entry point?

## Out of scope

New reactions, anonymous voting, net scores, vetoes, or response reasons.
