# Learning Release: Unified Plan Reaction Guide

## Concept To Build

The Plan row offers one neutral reaction button that opens positive and negative emoji choices in a floating bottom guide.

## Buildable Slice

Must be real:

- one neutral row affordance;
- balanced emoji-only Upvote and Not for me sections;
- an isolated Hard pass that expands the guide for an optional 140-character reason;
- an owner/caregiver acknowledgement before a hard-passed recipe moves to Groceries;
- one active response per person, removed by tapping the selected pill;
- accessibility labels for every emoji choice;
- existing reaction counts and participant disclosure unchanged.

Intentionally excluded: preset reason categories, permanent vetoes, profile-level food-need inference, or net scoring.

## Release Channel

Local build for immediate Simulator review, followed by the existing Recipes release path.

## Reversibility

The reaction IDs, optional reason, and candidate-scoped acknowledgement are additive and can be retired without rewriting existing Plan lifecycle or Grocery history.
