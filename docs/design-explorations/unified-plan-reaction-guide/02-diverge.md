# Diverge: Unified Plan Reaction Guide

Axis: how positive and negative choices are disclosed.

1. **Paired resting controls** — positive and negative actions stay in the row. Fastest negative response, but the idle thumbs-down resembles negative state and adds competing chrome.
2. **One neutral popover** — one smile-plus opens all emoji in a compact anchored menu. Small, but constrained space and stacking inside the Plan drawer make it less resilient.
3. **One neutral floating guide** — one smile-plus opens Upvote and Downvote sections in the existing floating `BottomGuide`. It preserves one row entry point, enough touch space, and the current overlay grammar.

All options preserve the current Plan object, remain optional, and avoid scores, public ranking, or forced participation. Option 3 best fits the system and the calm UX bar.
