# Yes-and: Focus seamless soundscapes

Original idea: repair six musical loop seams and add continuous nature ambience to the existing Focus picker.

## Adjacencies considered

1. **Yes, and distinguish music from nature.** Grouping improves scanning without adding a new surface. Serves `jtbd-carry-intentions-into-action`; cost delta low; anti-pattern check passes.
2. **Yes, and make loop quality an asset contract.** Add repeat-boundary measurements and audition renders to the existing audio audit. Serves `jtbd-trust-this-app-with-my-life`; cost delta low; passes.
3. **Yes, and preserve the selected environment offline when cached.** This already follows the catalog contract; cost delta none; passes.
4. **Yes, and allow layered music plus rain.** This could create richer personalization, but adds mixing state, gain interactions, and more playback ownership. Cost delta high; defer.
5. **Yes, and rotate tracks automatically.** This introduces surprise and turns a chosen environment into programming. Cost delta medium; reject for this job.
6. **Yes, and add favorites/download controls.** This adds management before Focus. Cost delta medium; reject.

## Frame recommendation

Run the loop with the original frame. Add only grouping and a durable loop-quality contract; do not expand into an audio system the user must maintain.
