# Evaluate Learning: Chore Inventory Member Grouping

## Learning questions

- Does the grouped default make the household division of recurring work immediately legible?
- Do caregivers understand that the funnel narrows the inventory while layers changes its structure?
- Are section headers enough identity, or do users still need assignee pills on every row?

## Evidence

Supporting evidence: Andrew can identify each member's and Household's chores in one scan, can switch to a flat list without instruction, and does not confuse the two controls.

Disconfirming evidence: the layers control is not discovered, the section order feels wrong, the grouped list feels substantially longer or noisier, or users repeatedly apply both controls expecting the same result.

## Instrumentation and decision rule

Use direct self-use and visual observation in the local learning slice; add no behavioral tracking for this refinement. Keep and later promote the behavior if it improves repeated caregiver review without explanation. Simplify or change the default if the extra structure becomes friction.
