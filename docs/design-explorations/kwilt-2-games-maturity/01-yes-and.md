# Yes-And: Kwilt 2.0 Games maturity

The broader opportunity is not another Games platform. It is an earned release catalog: every visible choice should make it easier to begin and more likely that the table asks for another round.

The open-ended expansion is intentionally bounded for this week. Future adjacencies—personalized recommendations, remote parity for every table, seasonal prompt packs, play history, and a creator system—add scope without proving the current games are fun. This release should improve the existing shelf and its weakest shared transition instead.

Job elevation: move from “Kwilt contains games” to “Kwilt reliably turns spare moments into shared play.”

Frame recommendation: run the loop with the original frame.
