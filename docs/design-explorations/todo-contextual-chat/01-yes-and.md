## Job elevation

The bigger opportunity is not “AI inside To-dos.” It is **callable, capability-contextual Chat**: one durable conversational system that can be invoked from the native work surface, use only visible bounded scope, act through that capability, and return the user to the result.

## Frame recommendation

**Run the loop with the original frame, while treating it as the first reusable contextual-Chat presentation.** Keep the learning release To-dos-specific. Do not broaden implementation to every capability until the phone interaction and thread-start semantics prove understandable.
