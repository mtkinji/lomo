# Yes-And: From Automatic Categorization To A Governed Household Plan

## Original idea

Kwilt should use connected-account evidence to create useful categories, assign uncategorized transactions, and set category limits inside the user's overall living target, while letting the user govern every assumption later.

## Adjacencies

## Job elevation

The idea is larger than auto-categorization or target-backed allocation. It is a governed household-planning system that creates useful truth automatically, remains honest about evidence coverage, learns the household's preferred structure, keeps monthly planning stable, and explains every consequence that changes the whole plan.

## Frame recommendation

**Run the design-thinking loop with the expanded frame.** Preserve the existing Money surfaces and versioned-plan mechanism, but treat account evidence, category identity, transaction assignments, planning-income basis, allocation, and consequence previews as one product system.
