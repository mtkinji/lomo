# Origin onboarding screenshot archive

Captured by Andrew on September 15, 2026; recovered September 22 from the original task's embedded image attachments.

All 27 screens from the onboarding walkthrough are saved alongside this index in sequence. These are the conversation-retained PNG copies (942 × 2048), not the original full-resolution clipboard files. No images were generated or reconstructed.

**Private reference material:** several images contain personal financial details, account information, entered context and a verification-code notification. PNGs and the provenance manifest are Git-ignored; do not publish or upload them without review and redaction. Local storage is durable across clipboard cleanup, but is not a cloud backup.

See [the reference study](../origin-first-run-reference.md) for Andrew's observations and preserve/translate/reject decisions. Origin's UI and photography are reference material, not Kwilt production assets.
