# Alternatives

1. Recent moments: concrete, recency-ordered choices from existing records. Best for recognition with minimal thought; fails when sources are empty. Fits current models; free writing remains available.
2. Capability picker: choose Explore, Goals, or Meals, then browse. Comprehensive but adds a taxonomy decision before seeing any actual moment.
3. Generated writing prompts: ask about the user's day and synthesize a caption. Useful for reflection but introduces inference and latency into a quick sharing job.

Choose 1. It removes recall effort, preserves private source details, and requires no generated claims, urgency, or default-public sharing. A short diverse preview avoids letting frequent Place visits crowd out Goals and Meals.
