# Alternatives
Axis: explicit configuration versus inferred recurrence.
1. Add a monthly weekday mode within Custom. Explicit, editable, fits existing scheduling and best serves this precise request. Costs one mode choice.
2. Infer “third Sunday” from the due date and offer a preset. Fast when the date is correct, fails when preparing ahead or no date is set.
3. Parse natural language. Fast capture but introduces ambiguity and a separate interpretation contract.
All preserve capture-first, private, one-copy behavior. Choose 1 for predictable control and minimal infrastructure.
