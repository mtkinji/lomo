# Evaluate Learning: explore-recovered-path

## Learning questions
- Is the recovered outing recognizable despite visible gaps?
- Do physical gaps and recap copy communicate uncertainty without requiring a second path style?
- Does the disclosure make the provenance clear without adding map clutter?

## Evidence plan
Inspect the owner’s synced map and recap in a native build. Compare the visible spans with the known outing window and confirm no segment crosses a source-sample outage.

## Disconfirming signals
The line implies precise traversal, is illegible on hybrid imagery, or the missing intervals make it misleading rather than useful.

## Decision rule
Keep the representation only if the owner recognizes the outing and understands why some spans are missing. Otherwise retain the data but hide the recovered route until a better presentation exists.

## Instrumentation
No new analytics. This owner-only repair needs direct visual inspection, not location-derived telemetry.
