# Converge: explore-recovered-path

## Chosen alternative
Evidence-labeled recovered path.

It is the only option that makes the failed outing visible without weakening normal recorded-route continuity or inventing missing movement.

## Capability delta
Before: the user cannot see the failed outing even though adjacent automatic samples exist.

After: the user can see supported portions of that outing as a distinct recovered path, with outages left blank and provenance stated in review.

Still unsupported: interpolated roads, exact claims between sparse samples, and automatic promotion of other sessions.

## Reductive decisions
- Reuse the existing map and recap.
- Add no setting, screen, badge, notification, special stroke style, or recovery workflow.
- Use one exceptional evidence field and one short disclosure.
- Keep the ordinary altitude path untouched.

## Activation
The recovered session appears wherever completed paths already appear. No education is shown unless the session is reviewed.

## Bet
We’re betting that physical gaps plus explicit recap copy are enough to keep recovery honest without introducing a second path style. If it reads as too precise, revisit by reducing which spans qualify rather than adding visual ornament or inference.

## Success signal
The failed outing becomes recognizable on the owner’s map, normal paths retain their strict behavior, and no segment crosses an observation outage.
