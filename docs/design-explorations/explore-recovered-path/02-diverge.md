# Diverge: explore-recovered-path

Axis: fidelity versus recoverability.

## 1. Keep the single recorded point
Preserve the strict existing contract and make no recovery. Best when there is no adjacent evidence; fails the user’s request because the outing remains invisible.

## 2. Promote automatic samples to a normal recorded path
Copy adjacent samples into the failed adventure and render the usual altitude route. Best for immediate visual similarity; rejected because it erases provenance and implies dense recording.

## 3. Evidence-labeled recovered path
Copy only the same-day adjacent samples into the failed adventure, mark the session as `ambient-recovered`, render trustworthy short spans with the normal path treatment, and leave longer outages blank. Best when sparse owner evidence exists; fails when samples are too weak or too far apart.

## 4. Road-match the outing
Infer a likely route between samples. Best for visual continuity; rejected because it would present a guess as lived evidence and may select the wrong road.

All options avoid productivity voice, pressure, public sharing, and anthropomorphic behavior.
