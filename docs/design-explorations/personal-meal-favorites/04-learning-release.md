# Learning release

Ship the smallest complete loop:

1. Favorite or unfavorite any meal from its card.
2. Persist that choice privately for the signed-in person.
3. Restore cached favorites while refreshing.
4. Show a `Your favorites` shelf when at least one favorited meal is available in the current catalog.

Do not use favorites as household votes, AI ranking authority, notifications, or a new top-level destination in this release.
