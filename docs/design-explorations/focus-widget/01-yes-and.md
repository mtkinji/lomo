# Yes-and: Focus Widget

The smallest useful release is a one-tap timer. It also opens several coherent adjacencies without requiring them now:

- A configurable default duration can make the widget personal without adding app setup.
- The resting widget can become a live countdown after the tap.
- Tapping an active countdown can return to pause, resume, soundscape, color, and end controls.
- Generic sessions can still count as showing up without pretending they advanced a Goal.
- Shortcuts and Siri can share the same standalone Focus entrypoint.
- A later reflection may invite the user to connect focused time to an Activity, but only by explicit choice.

The job elevation is not “more timers.” It is making the moment of readiness easy to honor.

## 2026-08-05 refinement

Adjacency expansion is intentionally skipped. The duration-and-audio moment is a
bounded correction to the widget entry flow. The job elevation is not maximal
speed; it is making two consequential choices feel calm and intentional without
turning them into persistent widget maintenance.
