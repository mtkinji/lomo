# Converge: One Active Meal Cycle

Choose **One Active Cycle**.

## Capability delta

Before, a user could add meals to a durable Plan, but the expanded drawer could
only close; the Meal Plan presented multiple competing actions; and the Grocery
screen placed optional tools before the actual list.

After, the user can move directly from the selected meals into the Plan, see one
state-derived primary continuation, and reach a grocery list whose first job is
reviewing and shopping its items.

## Reductive decisions

- No Food hub and no permanent stepper.
- The Plan drawer close control only closes; it no longer claims to finish work.
- The expanded Plan has one explicit continuation into Meal Planning.
- The Meal Plan has no “New cycle” action while a cycle is active.
- Starting a plan begins with choosing food, not choosing a planning mode.
- Family input remains visible but optional.
- Planning context follows the actual plan instead of preceding it.
- Grocery list items precede savings, household extras, and store observations.
- Shop is available only after the list is ready.

## Activation

The first + on a meal creates the cycle. The Plan count and drawer make the
result visible. No tour or setup copy is needed.

## Bet

We are betting that continuity becomes legible when every completed choice
reveals one natural next move. If users still feel lost, revisit the return path
and persisted-state presentation before adding explanatory navigation.
