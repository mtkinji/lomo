# Diverge: Meals End-to-End Continuity

Axis: explicit workflow chrome versus context carried by the active meal cycle.

## A. Food Hub

Add a single overview with Recipes, Plan, Groceries, and current progress.
Strong orientation, but it duplicates the already polished inventory, risks a
dashboard, and adds a place Maya must remember to visit.

## B. Permanent Journey Rail

Show Choose → Decide → Shop across every Food screen. State is legible, but the
rail turns household life into a pipeline and spends permanent space explaining
Kwilt’s architecture.

## C. One Active Cycle

Keep the inventory, recipe, plan, and grocery screens distinct. Carry the active
Meal Plan through them with a compact count/state and give each state one honest
next action. The transition itself teaches the model.

This best fits Maya, reuses current surfaces, and does not block capture. It
touches Recipe, Meal Plan, and Grocery records only through their existing
owners. It avoids dashboards, productivity voice, forced commitment,
anthropomorphic AI, and default-public sharing.
