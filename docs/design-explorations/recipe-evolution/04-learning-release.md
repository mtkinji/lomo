# Learning Release: Recipe Evolution

## Concept To Build

Update one attached personal recipe by describing or directly editing changes, with immutable version history and offline-safe saving.

## Buildable Slice

Must be real: structured suggestion contract, editable shared draft, immutable save, account-keyed offline queue, device-current pending state, history list, read-only historical view, append-only restoration, and source lineage.

Can be thin: text input before voice, automatically summarized changes instead of detailed comparison, Andrew-only production-hidden rollout.

Excluded: shared ownership, automatic merge, public editions, background on-device AI, and version management settings.

## Release channel

Production-hidden after local source tests and Simulator behavior, followed by a cabin-mode network-disabled session and reconnect conflict test. Backend and signed-device evidence remain separate gates.
