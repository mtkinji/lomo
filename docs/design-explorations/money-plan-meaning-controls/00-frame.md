# Frame

## Audience and job

- Audience: `audience-aspirational-family-organizers`
- Representative persona: Maya
- Hero JTBD: `jtbd-move-the-few-things-that-matter`
- Job flow: `job-flow-maya-review-budget-reality-before-spending`
- Underserved moments: establish the plan assumptions, then correct an assumption
  when the answer does not match household reality.

In Maya's voice:

> When I review flexible money, let me see and correct the plan assumptions that
> decide the number without turning me into a budget administrator.

## Aspirational challenge

How might Kwilt make the few assumptions behind flexible spending visible and
correctable at the moment they matter, while preserving one coherent plan model?

## Constraints

This is a fit-the-system refinement. It reuses the living-plan screen, category
editor, category assignment, and bottom-drawer grammar. It does not add a new
planning dashboard, a second transaction role system, or a new category axis.
