# Learning release

Release first as a local iPhone build.

The learning target is comprehension and correction:

1. Can a customer find where the 70% target is changed from the flexible answer?
2. Can they explain the difference between `Counts as` and `Funding rhythm`?
3. Can they see why a transaction is protected or flexible and correct it
   without encountering a second role switch?

Proof path: Budget -> What's included -> living target; Category -> Change plan
-> Counts as; Transaction -> Plan treatment.
