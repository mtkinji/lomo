# Yes-And: Contextual Recipe Chat

Original idea: launch Chat from Recipe Home with recipe-specific offer cards.

**Yes, and what if it could help a recipe survive a missing ingredient?**
- Serves: `jtbd-move-the-few-things-that-matter`
- Job elevation: move from recipe admiration to a workable meal.
- New value: explains substitution consequences instead of naming a generic swap.
- Cost delta: low
- Anti-pattern check: pass when the user names the constraint and the original remains visible.

**Yes, and what if it could preserve a household variation for next time?**
- Serves: `jtbd-trust-this-app-with-my-life`
- Job elevation: turn one-off adaptation into reviewed family knowledge.
- New value: creates a path toward an explicit personal version rather than overwriting source material.
- Cost delta: medium
- Anti-pattern check: pass only with proposal, review, and commit boundaries.

**Yes, and what if it could fit the time, servings, and equipment available tonight?**
- Serves: `jtbd-move-the-few-things-that-matter`
- Job elevation: answer “can we actually make this?” in context.
- New value: combines multiple practical constraints in one conversation.
- Cost delta: low
- Anti-pattern check: pass; no optimization or productivity framing.

**Yes, and what if it could work from what is already in the kitchen?**
- Serves: `jtbd-move-the-few-things-that-matter`
- Job elevation: reduce waste and unnecessary shopping.
- New value: separates safe substitutions from still-needed ingredients.
- Cost delta: low now, higher when pantry evidence becomes authoritative.
- Anti-pattern check: pass when Kwilt asks rather than pretending it knows pantry state.

**Yes, and what if the same conversation could later hand off to planning, groceries, or cooking?**
- Serves: `jtbd-carry-intentions-into-action`
- Job elevation: keep the food cycle connected without collapsing capability ownership.
- New value: reviewed downstream proposals can continue from the same durable thread.
- Cost delta: high
- Anti-pattern check: pass only through capability-owned actions and receipts.

## Frame recommendation
Run the loop with the original frame. The four offers expose the larger food cycle without making this release own every downstream action.
