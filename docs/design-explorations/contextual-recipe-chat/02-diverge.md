# Diverge: Contextual Recipe Chat

Axis: how much structure Chat provides before the person writes.

## A. One open prompt
Add the Chat control and open a scoped empty timeline with only the recipe chip. This is maximally quiet and fits the current contextual drawer, but it does not solve the prompt-invention problem the user named.

- Best when: people already know what they want to ask.
- Fails when: the recipe needs adaptation but the person cannot name the useful shape of help.
- System fit: excellent.
- Anti-pattern check: pass.

## B. Recipe-shaped offer cards
The native host supplies four compact cards for substitution, personal variation, tonight's constraints, and food on hand. A tap submits the card's full prompt as the first visible user turn and begins the response immediately.

- Best when: a small number of recognizable jobs covers most Recipe Home questions.
- Fails when: cards read like a feature catalog or imply that submitting the conversation also changed the Recipe.
- System fit: strong; extends the existing snapshot and reuses the shared quick-start card anatomy.
- Anti-pattern check: pass with quiet styling and no anthropomorphic copy.

## C. Automatic recipe assessment
Opening Chat immediately analyzes the recipe and writes a tailored assistant message with suggested changes.

- Best when: contextual inference is reliably useful without user intent.
- Fails when: it spends time, invents a constraint, or feels like unsolicited critique.
- System fit: weak; creates a thread/message before user intent and increases evidence cost.
- Anti-pattern check: fails calmness and consent; discard.

## D. Inline recipe tools
Place substitution and revision controls directly inside ingredients and instructions, with Chat as a secondary explanation layer.

- Best when: the dominant job is precise direct manipulation.
- Fails when: every line becomes tool chrome and Recipe Home stops being a clear read.
- System fit: medium; materially changes Recipe Home interaction grammar.
- Anti-pattern check: pass only after stronger usage evidence.
