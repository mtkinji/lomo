# Creative direction

Use the existing photographic Focus-video family without new chrome. The low camera, reflective alpine pool, granite, brush, and soft distant mountains create a quiet horizontal field that tolerates both landscape display and the existing portrait center crop. Preserve the current dark scrim and restrained timer controls so the place remains atmosphere rather than content.
