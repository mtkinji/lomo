# Frame: Bishop Lakes Focus environment

## Restated in user voice

When Marcus has chosen the work, he wants a quiet alpine environment that helps him settle without adding another setup or media-management layer.

## Target and job

- Audience: `audience-burned-out-productivity-power-users`
- Persona: **Marcus**
- Hero JTBD: `jtbd-move-the-few-things-that-matter`
- Supporting JTBDs: `jtbd-carry-intentions-into-action`, `jtbd-trust-this-app-with-my-life`
- Job-flow gap: `job-flow-marcus-move-the-few-things-that-matter`, step 5, “Decide what to do next,” currently 3/5.

## System posture

**Fit the system.** Bishop Lakes is another coordinated visual-and-audio choice in the existing Focus environment catalog. It does not add a new picker, player, download control, or orientation preference.

## Design challenge

How might Bishop Lakes help Marcus cross quietly from decision into action while preserving immediate Focus start, optional media, orientation freedom, and graceful fallback?
