# Diverge: Budget Settings

Axis: one composed page versus navigation hub versus retained contextual split.

## A. One canonical composed page

Main Settings and the Budget ellipsis open the same Budget page. Existing Money plan controls appear directly, followed by category recovery and links to privacy and household access. Best when the global control set is compact; fails if it grows into a dashboard. Fits the current grouped-settings grammar and introduces no new object model.

## B. Budget settings hub

The canonical page contains rows for Plan, Categories, Privacy, and Household, each opening a subpage. Best when each area has many controls; fails now because it adds an extra tap and preserves the confusing Money plan destination under a new label.

## C. Contextual plan plus global administration

The Budget ellipsis keeps opening Money plan while main Settings gets a separate Budget administration page. Best when plan changes are strongly month-contextual; fails the user's stated expectation that these are the same global settings family.

All three avoid productivity voice, dashboards, forced commitment, AI mutation, and sharing changes. They do not touch Kwilt's four-object model or capture behavior.
