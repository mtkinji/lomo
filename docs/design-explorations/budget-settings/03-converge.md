# Converge: Budget Settings

## Chosen alternative
One canonical composed page.

It best matches user expectation and the current Settings grammar with the smallest navigation model. The hub is premature; the split is the confusion being removed.

## Capability delta

Today, the user cannot reliably predict where Budget-level settings live. Afterward, main Settings and Budget's ellipsis open the same page, where plan controls and additive category recovery are available. The release still does not bulk-reset, rename, delete, or overwrite categories.

## Reductive decisions

- Replace three root Money rows with one Budget row.
- Fold Money plan into Budget settings rather than nesting it.
- Restore only missing canonical categories; never reset user categories or amounts.
- Keep category-specific settings on category detail.
- Add no dashboard, mode switcher, or separate category-management inventory.

## Activation

Discover organically from main Settings and contextually from Budget's ellipsis. No coachmark is needed.

## Bet

We're betting that a single composed page makes global Budget maintenance predictable without becoming configuration-heavy. If the page grows beyond a calm scan, revisit with progressive subpages.

## Success signal

From either entry point, the user reaches the same Budget page and can restore missing defaults without changing existing categories.
