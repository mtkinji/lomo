# Evaluate Learning: Budget Settings

## Learning questions
- Do users understand that Budget settings owns durable behavior rather than the current month?
- Does combining plan controls and category recovery remain calm?
- Does restore-defaults feel safe and produce the expected category set?

## Evidence
- Enter from main Settings and Budget's ellipsis in Simulator.
- Exercise existing, partially missing, and already-complete category sets.
- Confirm plan controls and privacy/access routes remain reachable.

## Disconfirming signals
- The page reads like a dashboard.
- Users still look for a separate Money plan destination.
- Restore creates duplicates or implies amounts were reset.

## Decision rule
Keep the composed page if both routes are predictable and recovery is additive. Split only if real controls outgrow a single calm settings scan.

## Instrumentation
Use automated mutation receipts and manual Simulator observation. Do not add behavioral analytics for this local learning release.
