# Home guidance — shadcn pattern review

September 10, 2026. Design study only; no further app styling changes in this pass.

## Diagnosis and job

The large card over-weighted a small decision. The subsequent text-only guide removed structure and reduced discovery to an unexplained product link. For Maya, the job is to resume meaningful work while recognizing another useful capability. The visual principle is: two understandable invitations, one compact Home module, then household activity. Home remains gray edge to edge.

## Official references checked

- [Item: icon, link, group and size examples](https://ui.shadcn.com/docs/components/base/item). Explicit media/content/action slots provide the best anatomy for short invitations.
- [Card: small size and header/action/footer composition](https://ui.shadcn.com/docs/components/base/card). Useful when one offer needs more explanation and a dedicated action.
- [Empty: media, title, description and content](https://ui.shadcn.com/docs/components/base/empty). Appropriate for a first-use welcome when there is no household activity yet.

These are upstream composition references, not copied web implementations. Preserve slot relationships, restrained borders and density. Translate with Kwilt typography, spacing, native touch targets and owned components. Reject web hover mechanics, arbitrary CSS sizes, generic promotional artwork, compulsory setup counts and new on-load overlays. No new dependency or component promotion is implied.

## Three directions

A. Item group — recommended. A small Next steps label and overview control precede two compact rows in one lightly outlined surface. The first row uses a capability icon, outcome title, short explanation and trailing action. The second row presents discovery with its own outcome explanation. The entire row enters its existing owner flow; menu actions stay separately accessible. Best for populated Home. Avoid adding rows until it becomes a checklist.

B. Small editorial card. One restrained header and short benefit statement, small explicit action, then a separate compact discovery footer. Best when the featured invitation needs context. It can again dominate the feed if padding, description or footer grows.

C. First-use Empty composition. A household symbol, invitation and small action, followed by a discovery item. Best only when Home has no activity. Do not manufacture empty status from absent membership or hide an existing feed.

## Recommendation and bet

Use A for regular Home. Keep the visual module separate from feed attribution and reactions. Preserve both roles; no ambiguous Try Money link with its benefit removed. Optional C can later adapt the empty state using real evidence. B remains a legitimate option for an unusually explanatory invitation, not the default.

Bet: the missing structure is a compact, recognizable action group rather than a larger hero. Success means a glance distinguishes what can be continued, what can be discovered and where household activity starts.
