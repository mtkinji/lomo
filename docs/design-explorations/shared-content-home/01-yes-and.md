# Yes-And: Shared Content Home

Original idea: Home should be the place where intentionally shared Kwilt content arrives.

## Adjacencies

**Yes, and what if every capability could publish through one recipient envelope?**

- Serves: `jtbd-trust-this-app-with-my-life`
- Job elevation: people learn one receiving grammar while capabilities retain authority.
- Cost delta: medium
- Anti-pattern check: pass; the envelope contains only an explicit share.

**Yes, and what if the same item remained discoverable in its owning capability?**

- Serves: `jtbd-move-the-few-things-that-matter`
- Job elevation: Home supports arrival while “Shared with me” collections support later retrieval.
- Cost delta: high, deferred per capability.
- Anti-pattern check: pass.

**Yes, and what if a notification always opened the exact Home item?**

- Serves: `jtbd-help-us-enjoy-being-together`
- Job elevation: interruption does not destroy the path back into participation.
- Cost delta: low; the stable delivery identity already exists.
- Anti-pattern check: pass.

**Yes, and what if rich cards made the sender and object recognizable before opening?**

- Serves: `jtbd-invite-the-right-people-in`
- Job elevation: a share feels like something a person sent, not a system event.
- Cost delta: low.
- Anti-pattern check: pass.

**Yes, and what if replies stayed contextual to the shared object?**

- Serves: `jtbd-invite-the-right-people-in`
- Job elevation: conversation carries the correct audience and context without turning Home into Chat.
- Cost delta: medium, reused where the capability already supports replies.
- Anti-pattern check: pass.

**Yes, and what if Home remained finite and deterministic as sharing volume grows?**

- Serves: `jtbd-trust-this-app-with-my-life`
- Job elevation: the user can understand why each item appears and reach a real end.
- Cost delta: low.
- Anti-pattern check: pass; no engagement ranking or infinite feed.

## Frame recommendation

Run the loop with the expanded frame: Shared Home is a receiving system for intentionally shared content, not merely a notification-recovery surface.
