# Yes-And: Kwilt Labs Explore

Original idea: make Explore the first off-by-default capability enabled through Kwilt Labs.

**Yes, and what if it could become one reusable activation contract?**

- Serves: `jtbd-trust-this-app-with-my-life`
- Job elevation: every emerging capability gets the same understandable opt-in boundary.
- New value: future Labs entries do not invent their own flags and storage.
- Cost delta: low
- Anti-pattern check: pass if the catalog stays code-owned and small.

**Yes, and what if disabling meant quiet, not erased?**

- Serves: `jtbd-trust-this-app-with-my-life`
- Job elevation: experimentation remains reversible without threatening personal history.
- New value: a user can pause Explore and return later.
- Cost delta: low
- Anti-pattern check: pass; reset/delete remain separate consequential actions.

**Yes, and what if activation governed runtime ownership as well as navigation?**

- Serves: `jtbd-trust-this-app-with-my-life`
- Job elevation: the visible promise and actual device behavior agree.
- New value: disabled Labs cannot keep syncing or recording in the background.
- Cost delta: medium
- Anti-pattern check: required; a cosmetic menu flag would fail.

**Yes, and what if deep links respected the same choice?**

- Serves: `jtbd-trust-this-app-with-my-life`
- Job elevation: old links and notifications cannot bypass consent.
- New value: one access policy covers menu, restore, and external entry.
- Cost delta: low
- Anti-pattern check: pass with a calm Labs recovery route.

**Yes, and what if Labs supplied an honest maturity boundary?**

- Serves: `jtbd-move-the-few-things-that-matter`
- Job elevation: users can distinguish dependable core tools from learning releases.
- New value: promotion out of Labs becomes an evidence decision rather than drift.
- Cost delta: low
- Anti-pattern check: avoid badges, feeds, voting, or novelty marketing.

Frame recommendation: **Run the loop with the original frame.** The platform value is real, but the smallest useful release is still one Settings-owned catalog with Explore as its first entry.
