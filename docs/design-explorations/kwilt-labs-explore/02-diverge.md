# Diverge: Kwilt Labs Explore

Axis: global experimentation mode vs capability-level choice vs invisible operator control.

## A. Master Labs Mode

One Settings switch reveals every experimental capability. It is easy to explain but couples unrelated risk and makes future activation all-or-nothing. Best when experiments form one coherent product; fails when a user wants Explore but not Pet or another Lab.

## B. Capability-Owned Labs Catalog

Settings > Kwilt Labs lists each emerging capability with its own switch. The shared catalog owns identity, default, persistence, and access policy; each capability owns setup and data. Best when capabilities mature independently. It adds the smallest reusable system extension and preserves user control.

## C. Remote Cohort Only

PostHog silently enables Explore for selected cohorts and no consumer switch exists. This is operationally convenient but does not satisfy deliberate activation, cannot communicate background location ownership, and repeats the current partial-gate problem.

All alternatives reject streak pressure, dashboards, public experimentation, and anthropomorphic framing. B best answers the design challenge without turning Labs into a product-management surface.
