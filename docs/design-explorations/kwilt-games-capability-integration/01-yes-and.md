# Yes-And: Kwilt Games Capability Integration

Original idea: make Games a first-class Fun capability inside unified Kwilt.

1. **Use the existing Kwilt install as the host advantage.** The organizer can reach play without finding a sibling app. Serves `jtbd-help-us-enjoy-being-together`; low cost.
2. **Let the shelf become a family invitation surface later.** A selected game can create a private room and invite before registration. Serves `jtbd-invite-the-right-people-in`; high cost.
3. **Keep local guest seats distinct from Kwilt people.** A typed name is not silently promoted to household identity. Serves `jtbd-trust-this-app-with-my-life`; medium cost.
4. **Make Chat hand off, never referee.** Chat may open a game or room, but rules and authoritative state remain Games-owned. Serves trust; medium cost.
5. **Let continuity earn itself after play.** Remembered players and results arrive only after a useful shared moment. Serves connection and trust; medium cost.

Frame recommendation: run with the original frame. The larger family-play layer is real, but the integration contract must be proven with a bounded native slice before catalog and remote expansion.
