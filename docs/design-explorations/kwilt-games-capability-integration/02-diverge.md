# Diverge: Games In Unified Kwilt

Axis: how Games enters the host without losing what already exists.

## A. Launch The Standalone App

Add a Fun row that deep-links to Kwilt Games. Low cost, but it is not a formal unified capability and preserves duplicate auth, navigation, and release ownership. Fails the request.

## B. Unadapted App-Within-An-App

Nest the standalone app, including Expo Router, duplicate auth storage, release configuration, and bundle assumptions. Highest apparent parity, but creates two competing application shells.

## C. Reduced Native Vertical Slice

Add Games as one registered Fun capability but move only Bank and Farkle initially. This isolates risk, but it also turns a formal integration request into an unrequested product reduction.

## D. Full Product, Narrow Host Adapters

Preserve the complete committed Games shelf and behavior while replacing only routing, auth/client ownership, deep-link ingress, native configuration, and release seams. This keeps the product people already had without creating an app within the app.

Anti-pattern check: D avoids dashboards, forced sign-in, fake affordances, productivity voice, duplicate ownership, and an unrequested MVP cut.
