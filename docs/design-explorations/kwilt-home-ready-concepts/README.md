# Eight ready concepts for Kwilt Home

September 9, 2026. All eight ideas have completed framing, expansion, three-way divergence, convergence, interaction definition and learning-release planning. **Ready for prototype implementation under explicit defaults; not yet user-validated or shipped.**

The governing product contract is the [Connected Moments v2 PRD](../../feature-briefs/kwilt-home-connected-moments.md). It contains exact entry/return behavior, copy, data ownership, authority boundaries, empty/error states and acceptance scenarios for every concept. Following Concept 02 review, it now includes the binding design-system pass: neutral Sumi actions instead of green, token-based post spacing, typography/component reuse, and native visual acceptance gates.

| ID | Ready concept | What the user gets |
|---|---|---|
| C1 | Your people, caught up | A compact people rail leading to a finite set of genuinely new authored moments. |
| C2 | A conversation already in motion | Real appreciation names and one reply preview leading into the existing thread. |
| C3 | Every kind of moment belongs | A shared visual grammar with expressive photo, text, goal, place and contribution bodies. |
| C4 | A moment with a useful next step | Clear place/goal previews and concrete source-backed invitations/actions. |
| C5 | Contributions worth noticing | Compact personal recognition of automatic household chores with truthful approval state. |
| C6 | Save the moment, find it again | A private Saved library and optional private collections, distinct from Explore places. |
| C7 | One editor, ready for the moment | Photo/Write/source entrances, one audience-aware Post action and recoverable drafts. |
| C8 | Explore and come back exactly where you were | Reliable scroll, media, conversation and source return with local pending feedback. |

## What changed through the loop

The rail is now a defined catch-up experience rather than decorative Stories. Inline conversation has deterministic selection and audience rules. Place saves and post bookmarks have separate destinations. Contributions distinguish gratitude from approval. Composer close/cancel behavior is defined even when publication is uncertain. Saved collections have ownership/deletion rules. Invitations are tied to supported source events. Continuity is a shared contract across every route.

## Recommended sequence

First: expressive posts, contextual responses, source previews, contributions, editor and continuity. Next: people catch-up and richer response summaries. Then: saved moments and collections. All eight stay in the ready set; staged implementation follows dependencies.

The next visual review should show three complementary screens: populated Home with people rail and mixed content; a conversation around a moment; and the refined editor. A fourth Saved/catch-up view can demonstrate the return paths. Use fictional content and identify the work as a concept until it runs in the actual app.
