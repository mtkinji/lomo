# Divergence: three alternatives for each concept

All alternatives target Maya's framed job. Fit indicates relationship to the current system, not validated usability. All preserve unanchored capture and explicit personal audiences. No alternative creates Arc/Goal requirements, planning Chapters, ranking of household worth, default-public sharing, forced posting, or AI-authored social behavior. Conditions in the final column are necessary to pass the context primer.

| Concept / axis | Alternative | Fit, best when, failure mode |
|---|---|---|
| C1 Catch-up / organization | **A. People rail → finite person catch-up** | Extends seen-state and person projection. Best for a quick visit with familiar people. Fails if it consumes the first viewport or duplicates household/person counts; dedupe in the view, not by summing bubbles. |
| C1 | B. Since your last visit digest | Requires a summary projection, optionally deterministic. Best after a long absence. Can feel like a report and hide individual voices; retain original posts and avoid AI claims about relationships. |
| C1 | C. People directory → histories | Reuses connections and author filtering. Best when deliberately finding someone. Weak at showing what is new on arrival. |
| C2 Response / conversation depth | **A. Appreciation line + one inline reply → thread** | Adds bounded authorized summaries to existing conversation. Best for seeing an opening without leaving the feed. Fails if previews overwhelm the original moment; cap at one. |
| C2 | B. Fully expanded threaded comments in feed | Extends list/reply model. Best for an active conversation. Fails in mixed browsing because long threads displace everyone else's moments. |
| C2 | C. Dedicated response inbox only | Needs a read-state inbox. Best for authors managing several discussions. Fails to convey social life while browsing the original feed. |
| C3 Expression / content structure | **A. Shared shell, content-specific bodies** | Reuses post types. Best for photos, text and source snapshots together. Fails if the number of variants grows without shared action/identity rules. |
| C3 | B. One uniform compact card for everything | Lowest system change. Best for scanning large volumes. Weak for emotional content and reproduces the current administrative feeling. |
| C3 | C. Full-screen one-moment-at-a-time reader | New navigation/reader. Best for immersive media. Weak for chores, invitations and quick mixed browsing; must not force autoplay. |
| C4 Participation / action location | **A. Compact source preview + truthful next action** | Reuses attachment snapshots and delivery commands. Best for moving from a moment to its useful capability. Fails if a preview implies live access the viewer lacks. |
| C4 | B. Every action opens source detail first | Strongest reuse. Best for complex source choices. Adds navigation for simple saves and can leave unsupported recipients at a dead end. |
| C4 | C. Complete mini-capability inside each post | Large authority/UI duplication. Best for a frequent, simple operation. Fails when Home becomes a second Chores/Explore/Goals implementation. |
| C5 Contributions / grouping | **A. Per-person contribution bundles** | Reuses current source grouping. Best for timely recognition with truthful details. Fails if very busy households still flood the stream; offer an authored-moments view. |
| C5 | B. One household summary per day | Needs new grouping and late-event reconciliation. Best for daily reflection. Delays recognition and blurs individual pending/approved transitions. |
| C5 | C. Dedicated contributions view only | Reuses filtered projection. Best for household review. Fails the original desire to encounter these contributions naturally in Home. |
| C6 Revisiting / organization | **A. Private Saved library + optional collections** | Extends saves; uses original visibility. Best for recalling both memories and places without setup. Fails if a save is confused with ownership or source access. |
| C6 | B. Shared household scrapbook | Needs collection audience/ownership rules. Best for co-curation. Risks surprise redistribution and creates another shared permission system. |
| C6 | C. Automatic journal / retrospective | New compilation and possibly Chapter input. Best for looking back across a season. Weak for precise retrieval; AI interpretation requires separate opt-in. |
| C7 Creation / entry strategy | **A. Intent-led entrances, one draft editor** | Reuses draft/publish pipeline and source offers. Best for both spontaneous photos and completed-goal handoffs. Fails if entrances fork into incompatible drafts. |
| C7 | B. Camera-first for every entry | Adds camera-forward flow. Best for live photos. Excludes writing, library-first sharing and source snapshots; retain alternatives to pass capture-first. |
| C7 | C. Multi-step creation wizard | Reuses fields in sequential screens. Best for complex composition. Overburdens ordinary sharing and makes interruptions harder. |
| C8 Continuity / interaction ownership | **A. Stable feed + local pending operations** | Extends client state and reconciliation. Best for exploration while requests run. Fails if optimistic state is treated as server truth. |
| C8 | B. Block and refresh after every action | Simple authority model. Best for rare high-impact changes. Fails for rapid appreciation and loses reading position. |
| C8 | C. Entire experience in a persistent full-screen reader | Large navigation change. Best for immersive content sequences. Weak for source actions, mixed media and quick return to other capabilities. |

Three distinct alternatives were considered for each of the eight concepts. The consistently selected A labels are ordering for readability, not a numerical score. Selection evidence and accepted costs are in [convergence](03-converge.md); exact contracts are in [the feature brief](../../feature-briefs/kwilt-home-connected-moments.md).
