# Diverge: Contextual UGC Safety

Axis: email-only escalation versus contextual intake versus a full in-app case center.

## A. Support handoff

Open a prefilled support email from content. It is cheap, but loses an authoritative object snapshot, has weak authorization guarantees, and does not meet the required in-app report intake contract.

## B. Universal contextual report and block

Offer Report from the content/person menu and always offer Block afterward. This
is compact for peer relationships but fails in caregiver-governed households and
can falsely imply that a child removed an adult's authority.

## C. Role-aware contextual help

Use one contextual intake, then let the server classify the existing relationship.
Peers can block immediately. Active Household members receive a private receipt;
children are told the reported person was not notified, while adults are directed
to manage Household access separately. This preserves the Household authority
model without weakening reporting.

## D. Safety center

Add report history, case status, appeals, and account enforcement in-app. It is appropriate for a public network, but creates privacy and operational complexity that Kwilt's private sharing model does not yet need.

Recommendation: C. It is the smallest truthful contract and does not turn
moderation into a product destination.
