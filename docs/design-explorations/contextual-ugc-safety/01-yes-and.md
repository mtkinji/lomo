# Yes-And: Contextual UGC Safety

Original idea: add the complete safety controls required for Kwilt's person-to-person content.

The useful adjacency is a reusable, role-aware safety response across future
shared surfaces. Every report can preserve the same contextual evidence, while
the next action depends on whether the relationship is peer sharing or an active
Household relationship. This elevates reporting from App Review plumbing to a
trust primitive without pretending every relationship is symmetric.

We are deliberately not expanding into public moderation, reputation scoring, automated punishments, parental surveillance, or a new inbox. Those add high cost and new harms without improving the current private-sharing job.

Frame recommendation: run the loop with a different frame: contextual help first,
with peer blocking and Household authority as distinct follow-up systems.
