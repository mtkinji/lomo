# Yes-And: On-device generative routing strategy

Original idea: Prefer on-device execution for each generative job when it can preserve a high-quality UX, and use cloud generation only when the device is unavailable or poorly suited.

## Job elevation

The larger opportunity is not “run more AI locally.” It is to make generative execution a governed product capability: each job has one outcome contract, multiple candidate providers, evidence-based promotion, explicit privacy-aware fallback, and cost that improves without lowering the user-visible standard.

## Frame recommendation

**Run the design-thinking loop with the original frame.** The product-wide typed-job strategy is already the right expansion. Do not broaden it into user-facing provider controls, a universal local agent, or an attempt to migrate every generation surface at once.
