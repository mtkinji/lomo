# Evaluate Learning: Chore Recurrence Resolution

## Learning questions

- Does a caregiver correctly choose between a time-window routine and persistent work?
- Does Charlie see one current responsibility after a missed scheduled occurrence?
- Does **You're caught up** accurately distinguish chore eligibility from Screen Time delivery?
- Does removing the token balance from the fixed bar improve hierarchy without making the balance feel lost?
- Does the adaptive correction entrance explain both the single-yesterday and multi-date cases?
- Can Charlie request credit for several real misses without believing today's chore is complete?
- Can Andrew resolve each correction without confusing it with work that needs another pass?

## Evidence

- Operate Feed Scout across a simulated day boundary and confirm yesterday is missed while today is actionable.
- Operate a **Keep open until done** chore across the same boundary and confirm its identity remains stable.
- Inspect incomplete, pending-approval, satisfied, tokens-off, and tokens-on footer states.
- Submit one and several earlier dates, confirm today's occurrence remains actionable, then count one request and leave another missed.

## Decision rule

Keep the contract if caregivers can predict both choices and the child never encounters duplicate actionable copies. Revisit labels before adding policy if comprehension fails. Do not add owed-copy accumulation without observed demand.
