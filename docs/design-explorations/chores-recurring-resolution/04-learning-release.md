# Learning Release: Chore Recurrence Resolution

## Concept To Build

Repeating chores either start fresh on their schedule or keep one occurrence open until done, while the child's footer states only the current agreement outcome.

## Buildable Slice

Must be real:

- persisted recurrence-basis choice on caregiver-created and edited chore series;
- deterministic time reconciliation for missed scheduled occurrences;
- no completion, token, streak, quota, or Screen Time credit for a miss;
- one actionable child occurrence per series;
- footer copy for active, pending-review, and satisfied agreements;
- token balance retained in agreement detail but removed from the fixed bar.
- contextual earlier-completion correction for missed assigned occurrences in the current week;
- multi-date child submission with occurrence-by-occurrence caregiver confirmation;
- correction credit applied once without closing or advancing today's occurrence.

Intentionally excluded:

- multiple owed copies, open-ended history administration, automatic retroactive credit, rotation, exemptions, reminders, backend reconciliation, and production Household authority.

## Release Channel

Local Kwilt Labs build. The slice remains simulated-member and local-persistence evidence, not a production Household claim.
