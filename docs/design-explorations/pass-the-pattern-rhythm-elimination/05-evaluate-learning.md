# Evaluate Learning: Pass the Pattern rhythm elimination

## Learning questions

- Does touch-down playback feel immediate on the actual iPhone speaker?
- Do equal file lengths also feel rhythmically uniform in context?
- Can mixed-age players understand and hit the generous beat window?
- Does elimination extend the fun, or leave players disengaged?
- Do the groove and note palette sound like one piece of music?

## Evidence plan

Run two complete family table rounds on a signed iPhone. Observe whether anyone comments on delay, disputes an off-beat miss, needs the continuation rule repeated, or asks to play another groove. Capture the specific groove and note combination behind any musical or timing complaint.

Supporting code evidence includes pure-rule tests, audio-call-order regression tests, asset duration/audit output, and Simulator interaction/visual proof. None substitutes for speaker and table-play evidence.

## Disconfirming signals

- Players tap correctly by ear but the game eliminates them.
- Notes still feel delayed despite touch-down triggering.
- The procedural grooves sound mechanical or clash with the note palette.
- Eliminated players disengage before the finish.

## Decision rule

Promote only after two complete rounds have no disputed timing failures and the group chooses a rematch or asks for another groove. Widen/disable timing judgment if fairness fails; replace the groove assets if musical cohesion fails; revisit elimination pacing if players disengage.

## Instrumentation

Use manual table notes only for this local release. Do not record per-player timing or performance analytics.
