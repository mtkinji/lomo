# Diverge: Pass the Pattern rhythm elimination

Axis: free musical expression versus strict rhythm judgment.

## A. Background color

Keep the current memory rules and play genre music underneath. Notes respond immediately, but timing is not judged.

- Fit: smallest implementation, but it does not fulfill "tap to the beat."
- Best when: music is only atmosphere.
- Fails when: players cannot tell whether rhythm matters.
- Anti-pattern check: pass, but weak capability delta.

## B. Beat-window elimination

Run a known-tempo percussion groove. Every note plays immediately, while deterministic rules judge whether the press landed inside a generous beat window. A wrong or off-beat tap eliminates only the active player; survivors begin the next genre round.

- Fit: extends the local rules and approved notes without adding configuration.
- Best when: the group wants memory, rhythm, and a clear winner.
- Fails when: device audio latency makes the audible beat disagree with the timing clock.
- Anti-pattern check: pass with neutral elimination copy and no performance metrics.

## C. Musical sandbox

Remove failure and let the group freely layer notes over genre loops, saving favorite patterns.

- Fit: strongest creative expression, but replaces rather than improves the game.
- Best when: the primary job is making music.
- Fails when: the group wants turns, stakes, or a finish.
- Anti-pattern check: pass, but creates a new authoring surface and persistence burden.

## Direction

Choose B. It is the only option that directly honors all observed feedback while remaining recognizably Pass the Pattern.
