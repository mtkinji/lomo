# Evaluate Learning: Stitch Five

## Learning questions

- Do players understand roll, pin, and stitch without a tutorial?
- Does the quilt board make score state clearer or merely prettier?
- Can players finish on one phone without turns feeling slow?
- Does the finished quilt create more satisfaction than a conventional scorecard?
- Is two-to-four-player shared play the right first posture?

## Evidence plan

Supporting evidence:

- Both groups start their first roll without coaching.
- Players use pinning correctly after its single contextual hint.
- No player disputes a score preview or total.
- Both groups finish; at least one voluntarily rematches or shares.
- Players refer to the board as something they made or want to keep.

Disconfirming evidence:

- Players repeatedly ask which category a patch represents.
- Decorative treatment reduces contrast or scanability.
- A full game feels too long for local pass-and-play.
- Players request a plain scorecard or abandon before every player completes thirteen stitches.
- The working title is confused with the established tabletop game.

## Instrumentation

For the local learning release, use an observation note per session: player count, time to first roll, coaching moments, score disputes, completion, rematch/share choice, and exact spontaneous comments. Do not add gameplay telemetry, dice-history collection, or player profiling for this slice.

## Decision rule

- Promote the interaction model if both groups finish without scoring disputes.
- Simplify the visual treatment if category lookup or contrast causes friction.
- Explore a short-board variant only if both groups identify duration—not comprehension or pacing—as the primary problem.
- Retire rather than inflate the concept if neither group wants to replay or share.
- Do not promote beyond Workshop until the production name is distinct.

## Expected next action

Run two local table sessions on a signed or TestFlight build, then update the feature brief and Games job-flow evidence with the observed result.
