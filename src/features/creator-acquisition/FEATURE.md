# creator-acquisition

Owns the planned continuation from an approved creator campaign into a
privacy-safe claim, optional activation challenge, retained paid value, and
auditable compensation.

## Boundaries

- Apple/RevenueCat owns subscription truth; a creator code never grants Pro.
- Kwilt owns first-qualified attribution, claim approval, commission rules, and
  the customer-side activation handoff.
- Friend referrals remain a separate install/AI-credit loop.
- Creator reporting never exposes private customer content or creator bank/tax data.
