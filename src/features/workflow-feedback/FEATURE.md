# Workflow feedback

Owns Kwilt's registered contextual feedback questions, attention budget,
identity-scoped local suppression, shared categorical renderer, and bounded
PostHog event contract.

Capability callers may request a registered moment after authoritative behavior
or from a specific visible UI context. They do not own arbitrary question copy,
reason taxonomies, persistence, sampling, or analytics properties. Behavioral
events remain authoritative for task success; feedback explains how the
experience felt.

Screen Time embeds the shared renderer inside its existing unlock guide. Other
pilot workflows use the standalone canonical bottom guide. V1 stores response
events in PostHog and only suppression metadata on device.
