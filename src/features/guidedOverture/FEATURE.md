# guidedOverture

Helps an unscoped new person understand several concrete ways Kwilt can help, choose one useful starting task at their own pace, and continue in Agent without restating that intent.

## Surfaces in this folder

- `guidedOvertureModel.ts` — versioned task-offer composition, manual progression, Agent handoff copy, and first-value contracts.
- `guidedOvertureEntryPolicy.ts` — starting-point precedence for generic orientation, exact destinations, resumptions, and returning users.
- `guidedOvertureEvaluationScenarios.ts` — six canonical persona pressure-test fixtures.
- `guidedOvertureResearchDecision.ts` — pre-registered Stage 1 advance/hold rules.
