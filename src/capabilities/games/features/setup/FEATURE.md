# setup

Owns the canonical player launcher shared by Bank, Farkle, player-aware local connection games, and joined-phone games. Bank defines the visual hierarchy: a centered game identity, familiar-player chips, explicit seats, a `Start game` action, and one path to bring in more phones. Individual games configure only the rules they actually need; they do not invent separate player-addition screens or launch language.

Show of Hands deliberately starts without the launcher because its anonymous finger-vote mechanic never uses names or seats. The basic dice roller is a utility rather than a player game. Joined-phone games reuse the launcher but may select only the host when the remaining players must join from their own devices.
