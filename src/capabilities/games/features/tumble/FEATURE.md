# tumble

Owns local Bank and Farkle shared play plus Basic Dice Roller, including player seating, remembered names, game decisions, feedback, and celebrations. Bank defaults to open banking: after a roll, the group can select every player banking the shared pot in one action; setup provides a native switch for groups that prefer turn-by-turn banking. After each local Bank roll settles, the Roll button shows a three-second cooldown while banking remains available so the table has a protected moment to decide.

## Notes

Local guests are seats, not accounts. For remote play, the host opens one capacity-bounded Bank table and nearby players join themselves by name through foreground discovery, QR, link, or code; the host does not issue invitations one player at a time. Remote control belongs to each participant, while canonical server authority belongs to the shared session. Basic Dice Roller is a utility, not a game.
