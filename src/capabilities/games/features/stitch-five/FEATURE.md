# Stitch Five

Owns the local, learning-gated five-dice quilt game: deterministic scoring and turns, fabric dice, the quilt board, result sharing, and rematch. It reuses Games setup and feedback but owns no account, persistence, remote-room, daily-challenge, or public-sharing behavior. “Stitch Five” replaces the conflicted Patchwork working title; formal naming clearance remains a graduation gate.
