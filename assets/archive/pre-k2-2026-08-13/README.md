# Pre-K2 Kwilt logo archive

This directory preserves the production logo assets that K2 replaced on 2026-08-13.

- Root files are the former shared app assets.
- `native/ios` preserves the generated App Icon, Screen Time shield, and widget copies.
- `native/android/notifications` preserves the density-specific notification icons.
- `native/android/launcher` preserves the legacy, round, and adaptive launcher artwork.

These files are historical source material only. Production code must use the active assets in `assets/`.
