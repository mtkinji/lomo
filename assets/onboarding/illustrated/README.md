Bundled derivatives of the approved connected-onboarding illustration studies. Built-in image generation used the Recipes drawn-editorial banner and Money study as style references. Masters and exact prompts remain in `docs/design-explorations/budget-led-quiet-compass/imagery/` (money-pause/README.md and onboarding-series.md).

## Native layout contract

- Job: recognize a useful household starting point and enter its existing setup.
- Authority: current user-approved mockup and copy, Kwilt UI constitution/tokens, owned Button/FullWidthActionDock/Logo/Typography. No new component-system dependency.
- Read order: invitation, supporting promise, illustration, primary setup action.
- Origin is a task-scoped composition reference: preserve invitation-first hierarchy; translate to Kwilt copy and Recipes-inspired art; reject its artwork, financial-health framing and certification badges.
- Copy is in normal flow above artwork with a real gap. Artwork is a fixed, noninteractive sibling outside the scroll view, anchored below measured copy; gestures never drag it. Text overflow can still scroll without bounce. Fixed action controls reserve scroll clearance and have a noninteractive parchment gradient behind them, not a hard-edged card.
- Starter choices use the canonical Card inside HapticPressable: one whole-card tap target, existing accessible name/hint, neutral surface and soft elevation. No extra nested surface or new navigation step.
- Retain Back, Skip, available-path filtering, real capability handoffs, and shoreline only on the opening. Keep the existing secondary chores entrance. No sample financial values, commercial offers, or production routing changes.
